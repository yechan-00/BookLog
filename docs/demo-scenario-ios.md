# BookLog 시연 영상 시나리오 (iOS 시뮬레이터)

> 작성: 2026-11-26 · 기준 커밋: `e0b7afc` (main) · 녹화 환경: iOS 시뮬레이터
> 목표 길이: 약 4분 (온보딩 포함 시 약 4분 40초)

PRD의 핵심 흐름(목표 → 책 고르기 → 집중 독서 → 기록 → 완독 → 다시 시작하기 → 알림)을 한 번에 보여 주도록 구성했다. 장면마다 **조작**, **화면에서 보여야 할 것**, **자막·내레이션 포인트**를 적었다.

---

## 0. 촬영 전 준비

### 0-1. 빌드

- [ ] 최신 `main`을 받는다. 앱 아이콘·알림 아이콘 변경(`app.json`, `assets/images/`)이 포함돼 있는지 확인한다.
- [ ] 아이콘은 네이티브 설정이라 다시 생성해야 반영된다.
  ```bash
  npx expo prebuild --clean --platform ios
  npx expo run:ios --configuration Release
  ```
  - **Release 빌드를 권장한다.** Debug 빌드는 개발 메뉴·LogBox 경고가 뜰 수 있고, 설정 화면에 개발용 `서재 미리보기` 버튼이 보인다.
  - **Expo Go로 녹화하지 않는다.** 알림 배너에 Expo Go 아이콘이 나온다.
- [ ] 시뮬레이터 홈 화면에 BookLog 새 아이콘이 보이는지 확인한다. 이전 아이콘이 남아 있으면 앱을 지우고 다시 설치한다.

### 0-2. 시뮬레이터 설정

- 기기: iPhone 16 Pro 등 노치가 있는 최신 기종을 권장한다. 앱은 라이트 모드로 고정돼 있다.
- 상태 표시줄 정리:
  ```bash
  xcrun simctl status_bar booted override --time "9:41" --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4
  ```
- 탭 위치 표시 (시청자가 어디를 눌렀는지 보이게):
  ```bash
  defaults write com.apple.iphonesimulator ShowSingleTouches 1   # 시뮬레이터 재시작 후 적용
  ```
- 녹화: 시뮬레이터 메뉴 `File > Record Screen` 또는
  ```bash
  xcrun simctl io booted recordVideo --codec=h264 booklog-demo.mp4   # Ctrl+C로 종료
  ```
- **한글 입력**: 시뮬레이터 키보드로 한글을 치면 느리고 오타가 나기 쉽다. 검색어·인덱스 제목·한줄평은 Mac에서 복사한 뒤 시뮬레이터에 `Cmd+V`로 붙여 넣는다. 필요하면 아래 "붙여 넣을 문구"를 미리 메모장에 둔다.

### 0-3. 데이터 준비 (테스트 계정)

앱은 원격 Supabase의 테스트 계정으로 자동 로그인한다. 아래 상태가 갖춰져야 기록·인사이트·먼지털이 장면이 비어 보이지 않는다.

| 항목 | 필요한 상태 | 쓰는 장면 |
| --- | --- | --- |
| 목표 | **시간 목표**, 촬영하는 요일이 목표 요일에 포함, 알림 켜짐 | 홈, 목표 도달 알림 |
| 독서 기록 | 이번 달에 여러 날의 세션 (달성·미달 섞여 있으면 좋음) | 기록, 인사이트 |
| 완독 책 | 2권 이상 | 책꽂이 |
| 책 A (완독 시연용) | `읽는 중`, 현재 페이지가 총 페이지 **10쪽 안쪽** (예: 240/248) | 장면 4~8 |
| 책 B (먼지털이용) | `읽는 중` 또는 `임시 중단`, 마지막 독서일이 **14일 이상 전** (묵은 먼지) | 장면 10 |
| 진행 중 세션 | **없어야 함**. 앱을 열었을 때 "진행 중인 독서가 있어요"가 뜨면 `종료하기` | 전체 |
| 등록할 책 | 서재에 **아직 없는** 책 1권을 정해 둔다 (예: 「불편한 편의점」) | 장면 3 |

- 먼지 단계 기준: 마지막 독서일부터 3일 미만은 깨끗함, 3일 이상은 옅은 먼지, 7일 이상은 먼지, 14일 이상은 묵은 먼지.
- 책 B를 앱에서 만들 수 없다면 (예전 날짜로 읽은 기록은 앱에서 남길 수 없다) Supabase 대시보드 SQL 편집기에서 해당 `user_books` 행의 `last_read_on`만 과거로 바꾼다. 세션·달성률에는 영향이 없다.
- 목표 도달 알림까지 보여 주려면 (선택): 촬영 당일, 오늘 목표까지 **1~2분만 남도록** 미리 읽어 두고 저장한다. 그러면 장면 4~5 사이에 "오늘의 독서 목표에 도달했어요" 배너가 뜬다.

### 0-4. 다시 찍기 어려운 동작 (테이크 계획)

아래 동작은 한 번 하면 데이터가 바뀌어 같은 조건으로 다시 찍을 수 없다. **리허설은 다른 책으로 하고, 본 촬영은 한 테이크에 끝낸다.** 장면별로 끊어 찍고 편집으로 이어 붙여도 된다.

| 동작 | 되돌리는 방법 |
| --- | --- |
| 책 등록 (장면 3) | 책 상세 → `서재에서 삭제` |
| 독서 기록 저장 (장면 7) | 책 상세 → 독서 기록 `삭제` |
| 완독 (장면 8) | 상태를 `읽고 싶음`으로 바꾸면 진행률이 0이 된다. 같은 조건으로 다시 찍으려면 완독 직전 상태의 책이 하나 더 필요하다 |
| 먼지털기 (장면 10) | 앱에서는 되돌릴 수 없다. DB에서 `dust_wipe_logs`의 해당 행을 지워야 한다 |

## 1. 장면 구성

| # | 장면 | 길이 | 핵심 메시지 |
| --- | --- | --- | --- |
| 0 | 앱 실행 | 5초 | 새 앱 아이콘 |
| 1 | 온보딩 (선택) | 40초 | 부담 없는 행동 목표 |
| 2 | 홈 | 20초 | 오늘 할 일이 한눈에 |
| 3 | 책 검색·등록 | 30초 | 카카오 검색, 총 페이지 입력 |
| 4 | 집중 독서 시작 | 15초 | 타이머 |
| 5 | 집중 모드 이탈·복귀 | 20초 | ★ 반응 메시지, 이탈 횟수 |
| 6 | 인덱스 남기기 | 25초 | ★ 페이지 + 짧은 제목 |
| 7 | 독서 종료·저장 | 25초 | 요약 |
| 8 | 완독 처리 | 25초 | 별점·총평 |
| 9 | 책꽂이 | 15초 | ★ 완독 책이 쌓임 |
| 10 | 먼지털이 | 25초 | ★ 멈춘 책 다시 펼치기 |
| 11 | 기록 탭 | 20초 | 달력·날짜별 기록 |
| 12 | 인사이트 탭 | 20초 | 달성률·연속 달성일 |
| 13 | 설정·알림 | 20초 | 알림 (앱 아이콘이 보이는 배너) |

---

### 장면 0. 앱 실행 (5초)

- **조작**: 시뮬레이터 홈 화면에서 BookLog 아이콘을 누른다.
- **보여야 할 것**: 새 아이콘. 잠시 로딩 뒤 홈 화면.
- **자막**: "테스트 계정으로 자동 로그인됩니다."

### 장면 1. 온보딩 (선택, 40초)

> 목표가 없는 계정에서만 나온다. 메인 테스트 계정에는 이미 목표가 있으므로, 넣으려면 **목표가 없는 별도 계정**으로 이 장면만 따로 찍는다 (`.env.local`의 테스트 계정 값을 바꾸고 앱을 다시 실행). 시간이 부족하면 빼고 자막으로 "첫 실행 시 목표를 설정합니다"만 넣는다.

- **조작**: 목표 유형 `시간` → 하루 목표 휠에서 15분 → 독서 요일 선택 → 독서 알림 `켜기` → 알림 시간 선택 → `독서 시작하기` → iOS 알림 권한 팝업에서 `허용`.
- **보여야 할 것**: "나만의 독서 목표를 설정해 보세요" 화면, 휠 피커, 권한 팝업, 홈으로 이동.
- **자막**: "결과가 아닌 행동 목표: 하루 15분부터."

### 장면 2. 홈 (20초)

- **조작**: 홈을 천천히 아래로 스크롤했다 다시 위로.
- **보여야 할 것**: 지금 읽는 책 카드, 오늘의 목표 (진행률), 연속 독서, 이번 주 독서, 나의 책꽂이 미리보기.
- **자막**: "오늘의 목표, 읽던 책, 연속 기록을 한 화면에서."
- 참고: "지금 읽는 책" 카드의 `독서 기록하기`로도 바로 독서를 시작할 수 있다. 이 시나리오는 완독 시연용 책 A로 읽어야 해서 장면 4에서 책 상세로 들어간다. 홈 카드에 책 A가 떠 있다면 장면 4를 `독서 기록하기`로 바꿔도 된다.

### 장면 3. 책 검색·등록 (30초)

- **조작**: 하단 `서재` 탭 → 오른쪽 위 `책 추가` → 검색창에 책 제목 붙여 넣기 → 결과에서 책 선택 → `총 페이지` 입력 → `서재에 추가`.
- **보여야 할 것**: 표지·제목·저자·출판사가 있는 검색 결과, 서재에 추가 시트, 서재 목록에 새 책 (`읽고 싶음`).
- **자막**: "카카오 책 검색으로 찾고, 총 페이지만 입력하면 등록 끝."

### 장면 4. 집중 독서 시작 (15초)

- **조작**: 서재에서 **책 A** 선택 → 책 상세에서 진행률 확인 → `집중 독서 시작`.
- **보여야 할 것**: 책 상세의 진행률, "독서 중" 화면의 타이머가 올라가는 모습, "시작 페이지 · 이탈 0회".
- **자막**: "타이머는 시작 시각 기준이라 앱을 나갔다 와도 정확합니다."
- 참고: `읽고 싶음`이나 `임시 중단` 책으로 시작하면 "'읽는 중'으로 바뀌어요" 확인이 먼저 뜬다 → `시작하기`.

### 장면 5. 집중 모드 이탈·복귀 (20초)

- **조작**: `Cmd+Shift+H`로 홈 화면으로 나간다 → 3~5초 기다린다 → BookLog 아이콘을 눌러 돌아온다.
- **보여야 할 것**: 상단 반응 메시지 (예: "돌아왔네요. 읽던 곳에서 다시 이어가 볼까요?"), "이탈 1회"로 바뀜, 타이머가 나가 있던 시간만큼 흘러 있음.
- **자막**: "★ 집중 독서 모드: 앱을 벗어나면 다시 책으로 불러옵니다."
- 반응 메시지는 5초 뒤 사라지므로 복귀 직후를 놓치지 않는다.
- (선택) 0-3에서 목표 도달 알림을 준비했다면 이 시점 전후로 "오늘의 독서 목표에 도달했어요" 배너가 뜬다.

### 장면 6. 인덱스 남기기 (25초)

- **조작**: `인덱스 추가` → 페이지 확인 → 제목 붙여 넣기 → (선택) 문장 붙여 넣기 → `저장`.
- **보여야 할 것**: 입력 모달, "이번 독서에서 남긴 인덱스" 목록에 p.페이지와 제목.
- **자막**: "★ 인덱스: 문장을 다 옮겨 적지 않고 페이지와 짧은 제목만."

### 장면 7. 독서 종료·저장 (25초)

- **조작**: `독서 종료` → `끝 페이지`에 **책 A의 총 페이지**를 입력 → 한줄평 붙여 넣기 → `저장`.
- **보여야 할 것**: "오늘 ○분 읽었어요.", "240p → 248p", "8페이지 읽음 · 집중 이탈 1회", 저장 토스트, "마지막 페이지까지 읽었어요. 완독 처리를 해 볼까요?"
- **자막**: "읽은 시간·페이지·집중 이탈이 요약됩니다."
- 1분이 안 되는 세션은 "○초"로 표시된다. 자연스럽게 보이려면 장면 4~6을 1분 이상으로 잡는다.

### 장면 8. 완독 처리 (25초)

- **조작**: `완독 처리하기` → 별점 선택 → 총평 붙여 넣기 → `저장` → 책 상세로 이동.
- **보여야 할 것**: 완독하기 화면, 책 상세의 "완독 기록" (독서 기간, 총 독서시간, 별점, 총평), 아래쪽 독서 기록과 인덱스 목록.
- **자막**: "완독하면 별점과 총평을 남기고 책꽂이에 꽂힙니다."

### 장면 9. 책꽂이 (15초)

- **조작**: 뒤로 가서 `서재` 탭 → 오른쪽 위 책꽂이 아이콘 (`책꽂이 열기`). 또는 홈의 "나의 책꽂이" → `전체 보기`.
- **보여야 할 것**: "완독 책꽂이"에 방금 완독한 책 A의 책등, 페이지 수에 따라 다른 두께.
- **자막**: "★ 완독한 책이 두께대로 쌓이는 책꽂이."

### 장면 10. 먼지털이 (25초)

- **조작**: 같은 책꽂이 화면의 "먼지가 쌓인 책"에서 **책 B**를 누른다 → 시트에서 먼지 상태 확인 → `먼지털기` → "책이 다시 깨끗해졌어요." 확인 → (선택) `이어 읽기`.
- **보여야 할 것**: 먼지 쌓인 표지 → 깨끗해진 표지.
- **자막**: "★ 오래 멈춘 책에는 먼지가 쌓이고, 털어내면 바로 이어 읽을 수 있습니다."
- ⚠️ `이어 읽기`를 누르면 새 독서 세션이 시작된다. 누른 장면에서 컷하고, 촬영 후 `독서 종료` → `기록 없이 종료`로 세션을 정리한다. 정리하지 않으면 이후 장면에서 "진행 중인 독서" 안내가 뜬다.

### 장면 11. 기록 탭 (20초)

- **조작**: 하단 `기록` 탭 → 달력 훑기 → 오늘 날짜 누르기 → 세션 카드 확인.
- **보여야 할 것**: 날짜별 달성/미달 아이콘, 오늘 칸의 완독 표지, "이날 완독한 책", 세션 상세 (독서 시간, 읽은 페이지, 시작·종료 페이지, 집중 이탈).
- **자막**: "달력에서 목표 달성 여부와 완독한 책을 한눈에."

### 장면 12. 인사이트 탭 (20초)

- **조작**: 하단 `인사이트` 탭 → 천천히 스크롤.
- **보여야 할 것**: 목표 달성률, 주간 달성 현황, 연속 목표 달성일·최고 기록, 기간별 독서 추이 그래프.
- **자막**: "목표 요일 기준으로 달성률과 연속 달성일을 계산합니다."

### 장면 13. 설정·알림 (20초, 마무리)

- **조작**: `홈` 탭 → 오른쪽 위 설정 아이콘 → 나의 목표·독서 알림 영역을 보여 준다 → `테스트 알림 보내기` → 2초 뒤 배너.
- **보여야 할 것**: 목표 설정 화면, 화면 위에서 내려오는 **BookLog 아이콘이 있는 알림 배너** ("북로그 알림 미리보기").
- **자막**: "목표 요일·시간에 읽지 않았다면 알림으로 다시 불러옵니다."
- 알림 권한이 꺼져 있으면 배너가 뜨지 않는다. 촬영 전 iOS 설정에서 BookLog 알림이 허용돼 있는지 확인한다.

## 2. 피해야 할 곳 (현재 구현 기준)

1. **진행 중 세션이 남은 상태**: 앱을 열면 "진행 중인 독서가 있어요" 팝업이 뜬다. 촬영 전에 정리한다.
2. **타이머를 오래 켜 두기**: 3시간을 넘기면 종료 화면에 실제 읽은 시간을 다시 입력하라는 안내가 붙는다.
3. **완독한 책의 완독 처리 다시 열기**: "이미 완독한 책이에요" 화면이 나온다.
4. **Debug 빌드의 설정 화면 아래쪽**: 개발용 `서재 미리보기` 버튼이 보인다 (Release 빌드에서는 안 보인다).

> 홈 `독서 기록하기` 버튼이 독서를 시작하지 않던 문제는 `fix/VIEW-05-home-start-reading`에서 고쳤다. 이 수정이 `main`에 머지된 빌드로 촬영한다.

## 3. 붙여 넣을 문구 (예시)

- 검색어: `불편한 편의점`
- 인덱스 제목: `다시 읽고 싶은 장면`
- 인덱스 문장: `삶은 어떻게든 관계이고 관계는 소통이다.`
  - 실제로 읽는 책의 문장으로 바꿔도 된다. 쓰기 전에 책에 실제로 있는 문장인지 확인한다.
- 한줄평: `마지막 장에서 오래 머물렀다.`
- 총평: `천천히 읽어서 더 오래 남는 책.`
