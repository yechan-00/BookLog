# BookLog 시연 영상 시나리오 (iOS 시뮬레이터 · Android 에뮬레이터)

> 작성: 2026-11-26 · 갱신: 2026-11-27 (Android 에뮬레이터 리허설 반영, 기준 커밋 `b20c85e`)
> 녹화 환경: iOS 시뮬레이터 또는 Android 에뮬레이터 (Android는 0-5 참고)
> 목표 길이: 약 4분 (온보딩 포함 시 약 4분 40초)

PRD의 핵심 흐름(목표 → 책 고르기 → 집중 독서 → 기록 → 완독 → 다시 시작하기 → 알림)을 한 번에 보여 주도록 구성했다. 장면마다 **조작**, **화면에서 보여야 할 것**, **자막·내레이션 포인트**를 적었다.

---

## 0. 촬영 전 준비

### 0-1. 빌드

- [ ] 최신 `main`을 받는다. 앱 아이콘·알림 아이콘 변경(`app.json`, `assets/images/`)이 포함돼 있는지 확인한다.
- [ ] 아이콘은 네이티브 설정이라 다시 생성해야 반영된다.
  ```bash
  npx expo prebuild --clean --platform ios
  npx expo run:ios --configuration Release
  ```
  - **Release 빌드를 권장한다.** Debug 빌드는 개발 메뉴·LogBox 경고가 뜰 수 있고, 설정 화면에 개발용 `서재 미리보기` 버튼이 보인다.
  - **Expo Go로 녹화하지 않는다.** 알림 배너에 Expo Go 아이콘이 나온다.
- [ ] 시뮬레이터 홈 화면에 BookLog 새 아이콘이 보이는지 확인한다. 이전 아이콘이 남아 있으면 앱을 지우고 다시 설치한다.

### 0-2. 시뮬레이터 설정

- 기기: iPhone 16 Pro 등 노치가 있는 최신 기종을 권장한다. 앱은 라이트 모드로 고정돼 있다.
- 상태 표시줄 정리:
  ```bash
  xcrun simctl status_bar booted override --time "9:41" --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4
  ```
- 탭 위치 표시 (시청자가 어디를 눌렀는지 보이게):
  ```bash
  defaults write com.apple.iphonesimulator ShowSingleTouches 1   # 시뮬레이터 재시작 후 적용
  ```
- 녹화: 시뮬레이터 메뉴 `File > Record Screen` 또는
  ```bash
  xcrun simctl io booted recordVideo --codec=h264 booklog-demo.mp4   # Ctrl+C로 종료
  ```
- **한글 입력**: 시뮬레이터 키보드로 한글을 치면 느리고 오타가 나기 쉽다. 검색어·인덱스 제목·한줄평은 Mac에서 복사한 뒤 시뮬레이터에 `Cmd+V`로 붙여 넣는다. 필요하면 아래 "붙여 넣을 문구"를 미리 메모장에 둔다.

### 0-3. 데이터 준비 (테스트 계정)

앱은 원격 Supabase의 테스트 계정으로 자동 로그인한다. 시연용 데이터는 한인웅 PC의 시드 스크립트(저장소 밖, `Claude outputs/demo-seed/seed_demo.py`)로 만든다. **스크립트는 테스트 계정의 서재·기록·목표를 모두 지우고 다시 만들며, 실행 전 데이터를 JSON으로 백업한다.** 날짜가 모두 실행일 기준이라 **촬영 당일 아침에 한 번 실행**한다 (iOS·Android가 같은 계정을 쓰므로 한 번이면 된다).

시드 실행 후 상태:

| 항목 | 상태 | 쓰는 장면 |
| --- | --- | --- |
| 목표 | 시간 목표 하루 20분, 월~토, 알림 21:00 켜짐 | 홈, 목표 도달 알림 |
| 오늘 기록 | 오늘 18분 읽음 → 시연 세션 **2분 뒤 목표 도달 알림** | 장면 4~6 |
| 독서 기록 | 최근 4주 세션 28건 (달성·과달성·미달·안 읽은 날·일요일 독서), 9일 연속 | 기록, 인사이트 |
| 책 A 「달러구트 꿈 백화점」 | 읽는 중, 288/296쪽 (홈 "지금 읽는 책") | 장면 4~8 |
| 책 B 「채식주의자」 | 읽는 중, 마지막 독서 16일 전 (묵은 먼지) | 장면 10 |
| 완독 | 「모순」, 「아몬드」 | 책꽂이 |
| 읽고 싶음 | 「작별하지 않는다」 | 서재 |
| 등록할 책 | 「불편한 편의점」 (서재에 없음) | 장면 3 |

- **민음사 판 도서는 쓰지 않는다.** 표지 비율이 맞지 않아 앱에서 깨져 보인다 (스크립트가 제외한다). 장면 3에서 등록할 책도 민음사 판을 고르지 않는다.
- 진행 중 세션이 **없어야 한다**. 앱을 열었을 때 "진행 중인 독서가 있어요"가 뜨면 `종료하기`.
- 먼지 단계 기준: 마지막 독서일부터 3일 미만은 깨끗함, 3일 이상은 옅은 먼지, 7일 이상은 먼지, 14일 이상은 묵은 먼지.

### 0-4. 다시 찍기 어려운 동작 (테이크 계획)

책 등록(장면 3), 기록 저장(장면 7), 완독(장면 8), 먼지털기(장면 10)는 한 번 하면 데이터가 바뀐다. **다시 찍으려면 시드 스크립트를 다시 실행하면 처음 상태로 돌아간다** (1분 안쪽). 장면별로 끊어 찍고 편집으로 이어 붙여도 된다.

### 0-5. Android 에뮬레이터로 녹화할 때

2026-11-27에 Android 15 에뮬레이터(Release 빌드)로 장면 2~13을 리허설했다.

- **빌드 (Windows)**: 기본 CMake 3.22.1은 긴 경로(260자 초과)를 처리하지 못해 네이티브 빌드가 실패한다. SDK Manager로 CMake 3.31.x를 설치하고 `android/local.properties`에 지정한다. `prebuild --clean`을 하면 이 파일이 지워지므로 다시 넣는다.
  ```properties
  sdk.dir=C:/Users/<사용자>/Android/Sdk
  cmake.dir=C:/Users/<사용자>/Android/Sdk/cmake/3.31.6
  ```
  ```bash
  npx expo prebuild --clean --platform android   # 위 local.properties 다시 넣기
  cd android && ./gradlew app:assembleRelease -PreactNativeArchitectures=x86_64
  adb install -r app/build/outputs/apk/release/app-release.apk
  ```
- **시간대**: 에뮬레이터 기본 시간대는 GMT라, 한국 시간으로 날짜가 바뀌어도 앱의 "오늘"이 하루 늦을 수 있다. 촬영 전 서울로 바꾼다.
  ```bash
  adb shell settings put global auto_time_zone 0
  adb shell service call alarm 3 s16 Asia/Seoul
  adb shell date   # KST 확인
  ```
- **탭 위치 표시**: `adb shell settings put system show_touches 1`
- **녹화**: 에뮬레이터 Extended controls → Record and playback, 또는 `adb shell screenrecord /sdcard/demo.mp4` (한 번에 최대 3분이라 장면별로 끊어 찍는다)
- **한글 입력**: PC에서 복사한 뒤 에뮬레이터 입력칸을 누르고 붙여 넣는다 (클립보드가 공유된다)
- **알림**: 처음 설치하면 알림 권한이 없다. 설정 화면에서 `독서 알림`을 켜거나 권한 팝업에서 허용한다. 알림은 화면 위 배너로 뜨고, 상태 표시줄에는 흰 책 실루엣이 보인다

### 장면 0. 앱 실행 (5초)

- **조작**: 시뮬레이터 홈 화면에서 BookLog 아이콘을 누른다.
- **보여야 할 것**: 새 아이콘. 잠시 로딩 뒤 홈 화면.
- **자막**: "테스트 계정으로 자동 로그인됩니다."

### 장면 1. 온보딩 (선택, 40초)

> 목표가 없는 계정에서만 나온다. 메인 테스트 계정에는 이미 목표가 있으므로, 넣으려면 **목표가 없는 별도 계정**으로 이 장면만 따로 찍는다 (`.env.local`의 테스트 계정 값을 바꾸고 앱을 다시 실행). 시간이 부족하면 빼고 자막으로 "첫 실행 시 목표를 설정합니다"만 넣는다.

- **조작**: 목표 유형 `시간` → 하루 목표 휠에서 15분 → 독서 요일 선택 → 독서 알림 `켜기` → 알림 시간 선택 → `독서 시작하기` → iOS 알림 권한 팝업에서 `허용`.
- **보여야 할 것**: "나만의 독서 목표를 설정해 보세요" 화면, 휠 피커, 권한 팝업, 홈으로 이동.
- **자막**: "결과가 아닌 행동 목표: 하루 15분부터."

### 장면 2. 홈 (20초)

- **조작**: 홈을 천천히 아래로 스크롤했다 다시 위로.
- **보여야 할 것**: 지금 읽는 책 카드, 오늘의 목표 (진행률), 연속 독서, 이번 주 독서, 나의 책꽂이 미리보기.
- **자막**: "오늘의 목표, 읽던 책, 연속 기록을 한 화면에서."
- 시드 직후 홈에는 「달러구트 꿈 백화점」 97%, 오늘의 목표 18분/20분, 9일 연속이 보인다.
- ⚠️ 장면 4는 **책 상세에서** 시작한다. 홈 카드의 `독서 기록하기`로 시작해 완독까지 가면, 완독 후 책 상세에서 뒤로 갈 때 이미 끝난 "독서 중" 화면이 타이머가 흐르는 채로 다시 나온다 (아래 "피해야 할 곳" 참고).

### 장면 3. 책 검색·등록 (30초)

- **조작**: 하단 `서재` 탭 → 오른쪽 위 `책 추가` → 검색창에 책 제목 붙여 넣기 → 결과에서 책 선택 → `총 페이지` 입력 → `서재에 추가`.
- **보여야 할 것**: 표지·제목·저자·출판사가 있는 검색 결과, 서재에 추가 시트, 서재 목록에 새 책 (`읽고 싶음`).
- **자막**: "카카오 책 검색으로 찾고, 총 페이지만 입력하면 등록 끝."
- 「불편한 편의점」을 검색하면 첫 결과가 「불편한 편의점(벚꽃 에디션)」(나무옆의자)이다. 표지가 잘 나와서 이것을 고른다. 총 페이지는 `268`.

### 장면 4. 집중 독서 시작 (15초)

- **조작**: 서재에서 **책 A 「달러구트 꿈 백화점」** 선택 → 책 상세에서 진행률 확인 → `집중 독서 시작`.
- **보여야 할 것**: 책 상세의 진행률 (288/296), "독서 중" 화면의 타이머가 올라가는 모습, "시작 페이지 288 · 이탈 0회".
- **자막**: "타이머는 시작 시각 기준이라 앱을 나갔다 와도 정확합니다."
- 참고: `읽고 싶음`이나 `임시 중단` 책으로 시작하면 "'읽는 중'으로 바뀌어요" 확인이 먼저 뜬다 → `시작하기`.

### 장면 5. 집중 모드 이탈·복귀 (20초)

- **조작**: 홈 화면으로 나간다 (iOS `Cmd+Shift+H`, Android 홈 버튼) → 3~5초 기다린다 → BookLog 아이콘을 눌러 돌아온다.
- **보여야 할 것**: 상단 반응 메시지 (예: "돌아왔네요. 읽던 곳에서 다시 이어가 볼까요?"), "이탈 1회"로 바뀜, 타이머가 나가 있던 시간만큼 흘러 있음.
- **자막**: "★ 집중 독서 모드: 앱을 벗어나면 다시 책으로 불러옵니다."
- 반응 메시지는 5초 뒤 사라지므로 복귀 직후를 놓치지 않는다. **메시지가 사라지면 아래 버튼들이 위로 올라간다.** 메시지가 떠 있을 때 `인덱스 추가`를 누르려다 사라지는 순간 `독서 종료`가 눌릴 수 있으니, 메시지가 사라진 뒤 누른다.
- **목표 도달 알림**: 시드로 오늘 18분을 읽어 둔 상태라, 세션 시작 **2분 뒤** "오늘의 독서 목표에 도달했어요" 배너가 뜬다. 장면 6까지 2분이 넘도록 진행하고, 배너를 확인한 뒤 장면 7로 넘어간다.
- ⚠️ 배너가 뜨기 전에 `독서 종료`를 눌렀다가 뒤로 돌아오면 목표 도달 알림이 취소되고 다시 예약되지 않는다. 그럴 때는 시드를 다시 실행하고 처음부터 찍는다.

### 장면 6. 인덱스 남기기 (25초)

- **조작**: `인덱스 추가` → 페이지 확인 → 제목 붙여 넣기 → (선택) 문장 붙여 넣기 → `저장`.
- **보여야 할 것**: 입력 모달, "이번 독서에서 남긴 인덱스" 목록에 p.페이지와 제목.
- **자막**: "★ 인덱스: 문장을 다 옮겨 적지 않고 페이지와 짧은 제목만."

### 장면 7. 독서 종료·저장 (25초)

- **조작**: `독서 종료` → `끝 페이지`에 **`296`** 입력 → 한줄평 붙여 넣기 → `저장`.
- **보여야 할 것**: "오늘 ○분 읽었어요.", "288p → 296p", "8페이지 읽음 · 집중 이탈 1회", 저장 토스트, "마지막 페이지까지 읽었어요. 완독 처리를 해 볼까요?"
- **자막**: "읽은 시간·페이지·집중 이탈이 요약됩니다."
- 1분이 안 되는 세션은 "○초"로 표시된다. 자연스럽게 보이려면 장면 4~6을 1분 이상으로 잡는다.

### 장면 8. 완독 처리 (25초)

- **조작**: `완독 처리하기` → 별점 선택 → 총평 붙여 넣기 → `저장` → 책 상세로 이동.
- **보여야 할 것**: 완독하기 화면, 책 상세의 "완독 기록" (독서 기간, 총 독서시간, 별점, 총평), 아래쪽 독서 기록과 인덱스 목록.
- **자막**: "완독하면 별점과 총평을 남기고 책꽂이에 꽂힙니다."

### 장면 9. 책꽂이 (15초)

- **조작**: 뒤로 가서 `서재` 탭 → 오른쪽 위 책꽂이 아이콘 (`책꽂이 열기`). 또는 홈의 "나의 책꽂이" → `전체 보기`.
- **보여야 할 것**: "완독 책꽂이"에 방금 완독한 「달러구트 꿈 백화점」이 「모순」, 「아몬드」 옆에 꽂힘, 페이지 수에 따라 다른 두께.
- **자막**: "★ 완독한 책이 두께대로 쌓이는 책꽂이."

### 장면 10. 먼지털이 (25초)

- **조작**: 같은 책꽂이 화면의 "먼지가 쌓인 책"에서 **책 B 「채식주의자」**를 누른다 → 시트에서 먼지 상태 확인 → `먼지털기` → "책이 다시 깨끗해졌어요." 확인 → (선택) `이어 읽기`.
- **보여야 할 것**: "16일째 손이 가지 않았어요 · 묵은 먼지" → 시트의 회색 상자가 짙은 초록으로 바뀜, "책이 다시 깨끗해졌어요."
- **자막**: "★ 오래 멈춘 책에는 먼지가 쌓이고, 털어내면 바로 이어 읽을 수 있습니다."
- ⚠️ `이어 읽기`를 누르면 새 독서 세션이 시작된다. 누른 장면에서 컷하고, 촬영 후 `독서 종료` → `기록 없이 종료`로 세션을 정리한다. 정리하지 않으면 이후 장면에서 "진행 중인 독서" 안내가 뜬다.

### 장면 11. 기록 탭 (20초)

- **조작**: 하단 `기록` 탭 → 달력 훑기 → 오늘 날짜 누르기 → 세션 카드 확인.
- **보여야 할 것**: 날짜별 미달성·달성·과달성 아이콘, 일요일에 읽은 날의 "목표 외 독서" 아이콘, 오늘 칸의 완독 표지, "이날 완독한 책", 세션 상세 (독서 시간, 읽은 페이지, 시작·종료 페이지, 집중 이탈).
- **자막**: "달력에서 목표 달성 여부와 완독한 책을 한눈에."

### 장면 12. 인사이트 탭 (20초)

- **조작**: 하단 `인사이트` 탭 → 천천히 스크롤.
- **보여야 할 것**: 목표 달성률, 주간 달성 현황, 연속 목표 달성일·최고 기록, 기간별 독서 추이 그래프.
- **자막**: "목표 요일 기준으로 달성률과 연속 달성일을 계산합니다."

### 장면 13. 설정·알림 (20초, 마무리)

- **조작**: `홈` 탭 → 오른쪽 위 설정 아이콘 → 나의 목표·독서 알림 영역을 보여 준다 → `테스트 알림 보내기` → 2초 뒤 배너.
- **보여야 할 것**: 목표 설정 화면, 화면 위에서 내려오는 **BookLog 아이콘이 있는 알림 배너** ("북로그 알림 미리보기").
- **자막**: "목표 요일·시간에 읽지 않았다면 알림으로 다시 불러옵니다."
- 알림 권한이 꺼져 있으면 배너가 뜨지 않는다. 촬영 전 BookLog 알림이 허용돼 있는지 확인한다 (설정 화면에 "알림 허용됨"이 초록으로 보이면 된다).
- 같은 테스트 알림을 연달아 보내면 기존 알림을 고치는 것으로 처리돼 두 번째부터는 배너가 다시 뜨지 않을 수 있다. 한 번에 찍거나, 알림 창에서 이전 알림을 지우고 보낸다.

## 2. 피해야 할 곳 (현재 구현 기준)

1. **진행 중 세션이 남은 상태**: 앱을 열면 "진행 중인 독서가 있어요" 팝업이 뜬다. 촬영 전에 정리한다.
2. **타이머를 오래 켜 두기**: 3시간을 넘기면 종료 화면에 실제 읽은 시간을 다시 입력하라는 안내가 붙는다.
3. **완독한 책의 완독 처리 다시 열기**: "이미 완독한 책이에요" 화면이 나온다.
4. **Debug 빌드의 설정 화면 아래쪽**: 개발용 `서재 미리보기` 버튼이 보인다 (Release 빌드에서는 안 보인다).
5. **홈 `독서 기록하기`로 시작해 완독까지 간 뒤 뒤로 가기**: 끝난 "독서 중" 화면이 타이머가 흐르는 채로 다시 나온다. 완독 시연은 책 상세에서 시작한다 (아직 고치지 않음).
6. **목표 도달 알림 전에 `독서 종료`를 열었다 돌아오기**: 목표 도달 알림이 취소되고 다시 예약되지 않는다 (아직 고치지 않음).

> 2026-11-26~27에 고친 문제 (main 머지): 홈 `독서 기록하기`가 독서를 시작하지 않음(#28), 스크롤 시 내용이 상태 표시줄과 겹침(#29), Android 알림이 배너로 뜨지 않음·설정 권한 표시가 갱신되지 않음(#30), 달력에 목표 외 독서가 표시되지 않음(#31).

## 3. 붙여 넣을 문구 (예시)

- 검색어: `불편한 편의점`
- 인덱스 제목: `다시 읽고 싶은 장면`
- 인덱스 문장 (선택): 넣으려면 「달러구트 꿈 백화점」에 실제로 있는 문장을 책에서 옮긴다. 없어도 저장된다.
- 한줄평: `마지막 장에서 오래 머물렀다.`
- 총평: `천천히 읽어서 더 오래 남는 책.`
