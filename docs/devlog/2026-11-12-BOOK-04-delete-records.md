## 1. Summary

사용자가 책 상세에서 인덱스, 독서 기록(세션), 서재의 책을 직접 삭제할 수 있게 했다. 중단 상태는 서재에 남는 "임시 중단"으로 두고, 서재에서 빼는 것은 삭제로 따로 한다. PRD에 삭제 요구사항이 없어, 새 요구사항 ID 없이 BOOK-03·04, INDEX-02의 수용 기준에 반영했다. 팀(한예찬)의 확인이 필요하다.

## 2. Requirements

- INDEX-02: 인덱스 삭제 추가 (진행 중)
- BOOK-04: 독서 기록 삭제, 서재에서 책 삭제 추가 (진행 중)
- BOOK-03: 중단 중 = 임시 중단(서재에 남음)으로 의미를 정리. 상태 변경 UI는 아직 없고 라벨만 "임시 중단"으로 바꿨다 (미착수)

## 3. Implementation

- `lib/api/indexes.ts` `deleteIndex`, `lib/api/sessions.ts` `deleteSession`, `lib/api/books.ts` `deleteUserBook`. 모두 지워진 행이 없으면 오류를 던진다(RLS는 남의 행을 오류 없이 숨기기 때문).
- 세션 삭제 뒤에는 책의 현재 페이지와 마지막 독서일을 남은 세션 기준으로 되돌린다(마지막 독서일은 먼지털이 단계에 쓰인다). 완독한 책은 페이지를 그대로 둔다.
- 책 삭제는 `user_books`를 지우면 세션·인덱스·리뷰·먼지털이 기록이 연쇄 삭제된다. 공용 `books` 행은 남는다. 진행 중인 독서가 있는 책은 삭제를 막고 먼저 종료하라고 안내한다.
- 세션·책 삭제 뒤에는 오늘 달성 여부가 바뀔 수 있어 참여 유도 알림을 다시 예약한다.
- `app/book/[id].tsx`: "한줄평" 섹션을 날짜·시간·페이지를 보여 주는 "독서 기록" 섹션으로 바꿨다(삭제할 기록이 보여야 해서). 인덱스·기록마다 삭제 버튼, 맨 아래에 "서재에서 삭제". 모든 삭제는 확인 대화상자를 거치고, 책 삭제 문구에 임시 중단을 안내한다.
- `utils/book.ts`: `paused` 라벨 "잠시 멈춤" → "임시 중단" (공용 파일).

## 4. Problems & Solutions

- 세션 삭제의 "삭제 + 책 값 되돌리기"는 RPC 한 번이 아니라 여러 호출이다. 중간에 실패하면 현재 페이지가 어긋날 수 있다. 원격 DB를 검증 없이 바꾸지 않으려 마이그레이션 없이 구현했고, 필요해지면 `delete_session` RPC로 묶는다.
- 서재 화면의 필터에는 중단 탭이 없다(PRD는 있음). BOOK-03 구현 때 한예찬과 맞춘다.

## 5. Verification

- `npx tsc --noEmit`, `npx expo lint` 통과
- 원격 DB에서 새로 등록한 책 한 권으로 확인함 (통과): 세션 2개 저장 → 최신 세션 삭제 시 페이지 90 → 40, 마지막 독서일 11-11 → 11-10 복귀, 이미 지운 세션은 0행(앱이 오류 표시), 인덱스 삭제는 그 행만, 책 삭제 시 세션·인덱스·리뷰 연쇄 삭제와 `books` 행 유지. 팀원 데이터는 건드리지 않았고 계정은 원래 책 2권 상태다.
- 확인하지 못함: 앱 화면(확인 대화상자, 삭제 후 이동). Android 실기기에서 확인해야 한다.
