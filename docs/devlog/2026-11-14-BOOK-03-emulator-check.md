## 1. Summary

Android 에뮬레이터(API 35)와 로컬 Supabase로 책 상세의 상태 변경과 완독 처리를 앱 화면에서 확인했다. 이전 DevLog(BOOK-03, READ-05, BOOK-04)에 "앱 화면 미확인"으로 남겨 둔 부분 중 이 두 흐름이 해소됐다.

## 2. Requirements

- BOOK-03: 책 상세의 상태 변경(읽는 중 → 임시 중단 → 완독)이 동작한다. 서재 탭의 상태 변경과 중단 탭은 한예찬 몫이라 "진행 중"으로 둔다.
- READ-05: 별점·총평 저장으로 완독 처리가 끝난다 (완료로 유지).

## 3. Implementation

코드 변경은 없다. 확인용 환경만 만들었다.

- Android SDK는 커맨드라인 도구로 설치했고(`C:\Users\hiw73\Android\Sdk`), AVD `BookLog_API35`(Pixel 7)를 썼다. 앱은 Expo Go로 실행했다.
- 앱을 로컬 Supabase에 붙이려고 셸 환경변수로 `EXPO_PUBLIC_SUPABASE_URL=http://10.0.2.2:54321`과 로컬 키를 넘겼다(`.env.local`은 건드리지 않았다). 에뮬레이터에서 호스트는 `10.0.2.2`다.
- 이를 위해 `lib/supabase.ts`가 개발 모드(`__DEV__`)에서만 `localhost`·`127.0.0.1`·`10.0.2.2`의 http를 허용하도록 고쳤다.

## 4. Problems & Solutions

- `.env.local`을 고치지 않고 환경변수로 덮어쓰려면 개발 서버를 `--clear`로 다시 띄워야 한다. 이전 서버가 8081 포트를 잡고 있어서 해당 프로세스를 종료한 뒤 다시 시작했다.
- adb는 한글을 입력할 수 없어 총평은 영문으로 넣었다.
- 새로 등록한 환경변수(`ANDROID_HOME`)는 이미 열려 있던 셸에 적용되지 않아 명령에 직접 지정했다.

## 5. Verification

- 책 상세(읽는 중): 진행률, 상태 변경 칩(임시 중단·완독), "읽는 중은 읽고 싶음으로 바로 못 돌린다"는 안내, 독서 기록과 삭제 버튼, 집중 독서 시작 버튼이 표시된다.
- 임시 중단 선택: 화면이 즉시 바뀌고 DB의 `status`가 `paused`로 저장됐다. 칩이 읽는 중·읽고 싶음·완독으로 갱신된다.
- 완독 처리: 별점 4와 총평을 저장하면 DB가 `completed`, 현재 페이지 263(총 페이지), 완독일 2026-11-13(기기 로컬 날짜), 리뷰 저장 상태가 된다. 책 상세에 독서 기간·총 독서시간·별점이 표시되고 "읽고 싶음" 되돌리기 칩이 남는다.
- 인덱스 추가(임시 중단 상태의 책): 폼에 현재 페이지(40)가 미리 채워지고, 제목을 넣어 저장하면 목록에 바로 나타난다. DB에는 페이지 40, 제목, 세션 없음으로 저장됐다 (INDEX-01·02).
- 인덱스 삭제: "삭제한 인덱스는 되돌릴 수 없어요" 확인 대화상자가 나오고, 삭제하면 목록이 "저장한 인덱스가 없어요"로 바뀌며 DB는 0건이 된다.
- 서재에서 책 삭제: "독서 기록, 인덱스, 완독 기록이 모두 함께 삭제돼요. 되돌릴 수 없어요. 잠시 쉬고 싶다면 상태를 임시 중단으로 바꿔 주세요." 대화상자가 나오고, 삭제하면 서재로 돌아가 "등록된 책 6권"(7권에서 감소)이 표시된다.
- 확인하지 못함: 실기기, 상태 변경 확인 Alert(이번 경로에서는 칩이 바로 반영됐다), 독서 기록(세션) 삭제 화면, 알림.
