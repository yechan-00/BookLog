## 1. Summary

독서 타이머, 집중 독서 모드, 세션 저장(READ-01·02·04)을 mock에서 Supabase 실제 데이터로 바꿨다. 책 상세에서 독서를 시작하면 진행 중 세션이 기기에 저장되고, 종료 화면에서 `finish_session`으로 저장된다. 독서 중 인덱스 추가(INDEX-01 일부)도 DB에 저장한다.

## 2. Requirements

- READ-01: 시작 시각 저장 + `현재 − 시작` 계산, 진행 중 세션 기기 저장, 앱 재실행 시 이어하기·종료 선택, 동시 세션 1개 제한 구현. 실기기 확인 전 (진행 중)
- READ-02: background → active 전환 시 반응 메시지와 이탈 횟수 +1 구현. 실기기 확인 전 (진행 중)
- READ-04: 끝 페이지(시작 이상, 총 페이지 이하)·한줄평 입력, 세션 저장, 시간·이탈 요약, 마지막 페이지면 완독 안내 구현. 실기기 확인 전 (진행 중)
- INDEX-01: 독서 중 추가만 구현. 책 상세에서의 추가는 12주 (진행 중)

## 3. Implementation

- `lib/reading/activeSession.ts`: 진행 중 세션을 `expo-sqlite/localStorage`에 JSON으로 저장. 읽을 때 형태를 검증하고, 깨진 값은 지운다. `beginReadingSession`이 동시 세션 1개를 지킨다.
- `hooks/useElapsedSeconds.ts`, `hooks/useFocusReturn.ts`: 경과 시간 계산과 background → active 감지. iOS의 `inactive`는 이탈로 세지 않는다.
- `hooks/useFocusData.ts`: 화면에 들어올 때마다 불러오는 로딩·오류·성공 상태 훅.
- `lib/api/sessions.ts`, `indexes.ts`, `reviews.ts`, `mappers.ts`, `books.ts`(조회 추가): `lib/api` 규칙(오류는 throw, `user_id` 인자 없음)대로 작성.
- `app/reading/session.tsx`, `finish.tsx`: `userBookId`를 받아 실제 데이터를 쓴다. 노트(P1)는 세션 화면에서 제거했다.
- `components/reading/ResumeSessionPrompt.tsx`: 앱을 켤 때 남은 세션이 있으면 이어하기·종료를 묻는다.
- 공유 파일 변경: `types/reading.ts`(`BookIndex`를 title 필수·quote 선택으로, `ActiveReadingSession` 추가), `types/book.ts`(`BookDetail` 추가), `constants/colors.ts`(표지 팔레트). `BookIndex` 변경은 `chore/index-title-type` 브랜치로 먼저 분리했다.

## 4. Problems & Solutions

- 인덱스 타입이 DB(`title` 필수, `quote` 선택)와 달라 `memo`를 없애고 `title`을 추가했다. 폼, mock, 표시 화면을 함께 맞췄다.
- `reading_sessions.pages_read`가 생성 컬럼이라 생성 타입이 nullable이다. 값이 없으면 끝 − 시작 페이지로 계산한다.
- 인덱스는 세션 저장 전에 DB에 바로 넣기 때문에 `session_id`가 비어 있다. PRD상 선택 값이라 허용했고, 세션과 연결할지는 INDEX 작업에서 정한다.
