## 1. Summary

타이머를 켜 둔 채 잊은 세션이 그대로 저장되지 않도록, 측정 시간이 3시간을 넘으면 종료 화면에서 실제로 읽은 시간(분)을 확인·수정하게 했다. 3시간 이하 세션은 이전과 같다.

## 2. Requirements

- READ-04: 긴 세션의 독서 시간 확인·수정 추가. 실기기 확인 전 (진행 중)

## 3. Implementation

- `app/reading/finish.tsx`: 측정 시간이 `LONG_SESSION_SECONDS`(3시간)를 넘으면 안내 문구와 "독서 시간 (분)" 입력을 보여 준다. 기본값은 측정한 분이고, 1분부터 측정한 분까지만 받는다.
- `finish_session`은 `ended_at − started_at`으로 독서 시간을 계산하므로, 수정한 시간은 종료 시각을 `시작 시각 + 입력한 분`으로 보내 반영한다. 마이그레이션은 필요 없다.
- 상한값은 이 화면에서만 쓰여 공용 `constants/`가 아닌 화면 파일 상수로 두었다.
- `utils/format.ts`(한예찬 작성): `formatDuration`이 1분 미만을 "0분"으로 보여 주던 것을 초로 표시하도록 고쳤다(30초 → "30초"). 1분 이상 표시는 그대로이고, 종료 화면·책 상세·세션 카드·홈·기록·인사이트에 함께 반영된다.

## 4. Problems & Solutions

- 점검에서 밤새 켜 둔 세션이나 강제 종료 후 다음 날 "종료하기"를 누른 세션이 10시간 넘게 저장되어 달성률·연속 독서일을 부풀리는 문제를 찾았다. DB에는 시간 상한이 없어 앱 종료 화면에서 막았다.
