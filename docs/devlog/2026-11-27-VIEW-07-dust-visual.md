## 1. Summary

책꽂이 책등과 먼지 상태 시트의 먼지가 거의 보이지 않던 문제를 고쳤다. 먼지를 책 윗면에 쌓이는 옅은 층과 흩어진 점으로 다시 그리고, 시트에서는 색 상자 대신 실제 표지 위에 먼지를 얹었다.

## 2. Requirements

- VIEW-07: 오래 손대지 않은 책에 먼지가 쌓여 보이고, 털면 사라진다

## 3. Implementation

- `components/books/DustOverlay.tsx`(신규): 단계(1~3)별로 윗면 먼지층 두께, 전체 베일, 점 개수를 정해 그린다. 그라데이션 라이브러리 없이 위쪽에서 시작하는 반투명 층 10장을 겹쳐 아래로 옅어지게 했다. 점은 R2 수열로 흩어 줄지어 보이지 않게 했다
- `components/books/BookSpine.tsx`(한예찬 소유): 기존 베일·점 대신 `DustOverlay`를 쓴다
- `components/books/DustBookSheet.tsx`(한예찬 소유): 책 색 사각형 대신 `BookCover`(표지 이미지)에 `DustOverlay`를 얹는다. 털면 먼지가 서서히 사라지고, "푹" 효과는 떠올랐다가 사라진다(전에는 70% 불투명도로 남아 표지를 가렸다)

## 4. Problems & Solutions

- 기존 먼지는 투명도가 두 번 곱해져 "묵은 먼지"도 실제 진하기가 약 16%였다. 어두운 책등 위 어두운 점은 거의 보이지 않았다 → 밝은 먼지색으로 바꾸고 윗면에 층을 쌓았다
- 반투명 띠를 이어 붙이면 경계마다 선이 생겼다 → 모든 층을 위쪽 끝에서 시작해 길이만 다르게 겹쳤다
- 점을 `(i * 상수) % 범위`로 배치하니 대각선으로 줄지어 보였다 → R2 저불일치 수열로 바꿨다

## 5. Verification

- `npx expo lint` 통과. `npx tsc --noEmit`은 기존 오류 1건(`/dev/library-preview` 경로 타입)만 남음
- Android 에뮬레이터(Release): "묵은 먼지" 책등과 시트 표지에서 먼지 확인, 먼지털기 시 먼지가 사라지고 깨끗한 표지가 남음
- 플랫폼별 분기 없이 기본 View만 써서 iOS도 같은 방식으로 그려진다(iOS 기기 확인은 못 함). 1·2단계 먼지는 시드 데이터에 없어 화면으로 확인하지 못함
